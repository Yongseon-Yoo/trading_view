# 컴포넌트 스펙: 장 마감 수급 리포트

> 상태: IMPLEMENTED - 샘플·자동 테스트 검증, 실제 키 통합 검증 대기

## 목적

당일 외국인·기관 수급과 거래 집중 종목을 표준화된 표로 제공한다. 시스템은 전일과 비교하거나 순환매 여부를 자동 판정하지 않는다.

## 입력

- 기준 거래일
- 조회 시장: KOSPI 또는 KOSDAQ
- 표시 개수: 10으로 고정
- 키움 REST API 인증정보
- 종목 기본정보 및 업종 매핑

## 출력

```text
EveningFlowReport
- trading_date
- generated_at
- foreign_buy_top[]
- foreign_sell_top[]
- institution_buy_top[]
- institution_sell_top[]
- trading_value_top[]
- sector_groups[]
- collection_status[]
```

각 종목 항목:

```text
- stock_code
- stock_name
- sector_name
- price
- change_rate
- net_amount_krw
- volume
- trading_value
- data_as_of
```

## 처리 규칙

1. KOSPI와 KOSDAQ 각각의 투자자별 순매수·순매도 금액 자료를 조회한다.
2. 거래대금 상위 종목을 조회한다.
3. 숫자형 문자열, 부호, 쉼표와 단위를 원 단위 정수값으로 변환하고 원본값과 원본 단위를 함께 보존한다.
4. 종목코드로 기본정보와 업종명을 결합한다.
5. 투자자와 매수·매도 방향별로 순매수금액 기준 Top 10 표를 생성한다.
6. 투자자별 순매수·순매도 Top 10을 각각 업종별로 묶고 금액을 계산한다. 두 방향을 상쇄하지 않는다.
7. 시장 및 투자자별로 업종 수급 양방향 가로 막대그래프를 생성한다.
8. 조회 결과와 데이터 기준 시각을 저장한다.

업종별 집계는 전체 시장의 완전한 자금 흐름이 아니라, 조회된 상위 종목 집합 안에서의 모아보기임을 차트 제목과 안내문에 표시한다.

## 업종 시각화 규칙

- 차트 제목: `Top 10 종목 내 업종 분포`
- 차트 형태: 0원을 중심으로 한 양방향 가로 막대그래프
- 양수 방향: 업종별 순매수금액 합계
- 음수 방향: 업종별 순매도금액 합계
- 구분: KOSPI·KOSDAQ 별도, 외국인·기관 별도
- 막대 레이블: 억원 단위 금액
- 상세 정보: 업종명, 정확한 금액, 포함 종목 수, 대표 종목
- 접근성: 색상 외에 부호, 축 방향, `순매수`·`순매도` 텍스트를 함께 제공
- 안내문: `전체 업종 수급이 아닌 투자자별 순매수·순매도 Top 10 포함 종목 기준`

## 성공 기준

- 외국인·기관의 매수·매도 표가 서로 분리된다.
- KOSPI와 KOSDAQ 결과가 서로 분리된다.
- 수급 금액이 원 단위로 정규화되며 순매수금액 기준으로 정확히 정렬된다.
- 화면의 기본 표시 단위는 억원이며 정확한 원 단위 값도 확인할 수 있다.
- 각 종목에 업종명이 표시된다. 업종을 찾지 못하면 `미분류`로 표시한다.
- 거래대금 상위 표를 볼 수 있다.
- 업종별로 종목 수, 수급 합계, 거래대금 합계를 볼 수 있다.
- KOSPI·KOSDAQ 및 외국인·기관을 구분한 업종별 양방향 막대그래프를 볼 수 있다.
- 차트만 보더라도 매수·매도 방향과 금액 규모를 구분할 수 있다.
- 데이터가 잠정치일 수 있다는 안내와 조회 시각이 표시된다.
- 시스템은 `순환매 시작`, `매수 추천` 같은 결론을 생성하지 않는다.

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| 장 마감 전 실행 | `장중 잠정 데이터`로 명시 |
| 휴장일 실행 | 직전 거래일 선택 안내 |
| 수급 값 누락 | 빈 값으로 보존하고 집계에서 제외 |
| 공급자 응답 단위 불명확 또는 혼재 | 해당 행을 순위에서 제외하고 수집 오류로 기록 |
| 업종 매핑 없음 | `미분류` 처리 |
| 일부 조회 실패 | 성공한 표만 표시하고 상태 기록 |
| 호출 제한 | 캐시 사용 또는 제한 재시도 |

## 범위 밖

- 전일 대비 자동 비교
- 순환매 자동 탐지
- 테마별 완전한 자금 흐름 계산
- 개인 및 프로그램 매매 데이터
- 개인 투자자 심리 점수
- 실시간 호가 또는 체결 분석
- 주문 실행

## 테스트

- 숫자·부호·단위 정규화 테스트
- 순매수금액 기준 Top 10 정렬 테스트
- 매수·매도 방향 분리 테스트
- 업종 매핑 및 미분류 테스트
- 업종별 합계 테스트
- 업종 차트 데이터의 양수·음수 방향 변환 테스트
- 일부 데이터 누락 테스트
- 장중·장후 상태 표시 테스트
