# 컴포넌트 스펙: 아침 뉴스 브리핑

> 상태: IMPLEMENTED - 실제 API 전용 및 0건 차트 충돌 회귀 테스트

## 목적

직전 국내 정규장 종료 이후 발생한 관심 종목 및 관심 테마 뉴스를 한곳에 정리한다. 시스템은 영향이나 매매 방향을 판단하지 않는다.

## 입력

- 관심 종목 목록
- 사용자가 직접 등록한 관심 테마와 복수 검색 키워드 목록
- 사용자가 직접 설정한 종목-테마 연결 정보
- 기준 시각
- NAVER API HUB 뉴스 검색 Application의 Client ID와 Client Secret
- 선택적 기존 뉴스 저장 이력

## 출력

```text
MorningBrief
- generated_at
- window_start
- window_end
- stock_price_snapshots[]
- stock_sections[]
- theme_sections[]
- news_volume_buckets[]
- collection_status[]
```

각 뉴스 항목:

```text
- title
- normalized_title
- source
- published_at
- url
- query_type: stock | theme
- query_value
- duplicate_count
```

각 종목 가격 스냅샷:

```text
- stock_code
- stock_name
- price
- price_label: previous_close | current_price
- change_amount
- change_rate
- market_status
- data_as_of
- collection_status
```

## 처리 규칙

1. 한국 거래일을 기준으로 가장 최근 정규장 종료 시각인 15:30을 계산한다.
2. 등록 종목의 최신 가격을 키움 REST API로 한 번 조회하고 시장 상태에 따라 `전일 종가` 또는 `조회 시점 현재가`로 표시한다.
3. 종목명과 테마 키워드별로 뉴스를 조회한다.
4. HTML 태그와 불필요한 공백을 제거한다.
5. 동일 URL을 제거한다.
6. 정규화한 제목이 같거나 충분히 유사한 기사를 하나의 이슈로 묶는다.
7. 조회 기간 밖의 기사를 제외한다.
8. 발행 시각 내림차순으로 정렬한다.
9. 종목·테마별로 조회 구간을 한 시간 단위로 나누고 기사 수와 이슈 수를 집계한다.
10. 기사 0건인 시간 구간도 포함한 시간대별 막대그래프 데이터를 생성한다.
11. 가격·뉴스 결과와 각각의 수집 상태를 함께 저장한다.

## 뉴스 발생량 시각화 규칙

- 차트 형태: 시간당 기사 수 세로 막대그래프
- 구분: 관심 종목별, 관심 테마별 개별 차트
- X축: `Asia/Seoul` 기준 날짜와 시간
- Y축: 동일 URL을 제거한 기사 수
- 상세 정보: 해당 시간의 기사 수와 유사 제목을 묶은 이슈 수
- 빈 구간: 0건 막대로 포함
- 요약 수치: 최근 1시간, 최근 6시간, 직전 장 마감 이후 전체 기사 수
- 해석 제한: `급증`, 감성, 가격 영향 또는 매매 방향을 자동 판정하지 않음

## 성공 기준

- 등록된 모든 종목과 테마에 대해 결과 또는 명시적인 `데이터 없음` 상태가 존재한다.
- 종목 카드에 가격, 전일 대비, 등락률, 가격 기준 시각과 `전일 종가` 또는 `조회 시점 현재가` 레이블이 표시된다.
- 같은 URL은 한 번만 표시된다.
- 유사 기사 묶음에는 대표 기사와 전체 기사 수가 표시된다.
- 종목·테마별 시간당 기사 수 차트가 표시된다.
- 기사가 없는 시간도 0건으로 표시되고 상세 정보에서 이슈 수를 확인할 수 있다.
- 최근 1시간·6시간·전체 구간의 기사 수가 차트와 일치한다.
- 기사 원문 링크를 열 수 있다.
- 월요일에는 직전 금요일 장 마감 이후 기사를 포함한다.
- API 일부 실패 시 성공한 검색 결과는 유지된다.

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| API 키 없음 | 설정 필요를 표시하고 가상 기사를 생성하지 않음 |
| 인증 실패 | 해당 공급자 실패 상태 기록 |
| 가격 조회 실패 | 가격 실패 상태를 표시하고 뉴스 브리핑은 계속 생성 |
| 호출 제한 | 지수 백오프 후 제한된 횟수만 재시도 |
| 검색 결과 없음 | 빈 목록과 `새로운 뉴스 없음` 표시 |
| 발행 시각 파싱 실패 | 해당 기사를 제외하고 오류 수 기록 |
| 제목만 다른 동일 기사 | URL 우선, 이후 제목 유사도로 묶음 |
| 휴장일 | 한국 거래일 달력을 이용해 직전 장 종료 계산 |
