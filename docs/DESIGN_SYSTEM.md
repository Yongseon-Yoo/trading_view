# 대시보드 디자인 시스템

> 상태: APPROVED - 2026-09-30 사용자 요청

## 방향과 경계

짧은 시간 안에 뉴스·수급·가격을 읽는 개인용 금융 리서치 화면이다. [스톡 주식 대시보드 디자인](https://kmong.com/portfolio/view/12246)의 어두운 배경, 밝은 정보 강조, 조밀한 정보 배치에서 분위기를 참고한다. 원본의 이미지, 로고, 텍스트, 카드 배치와 장식 요소를 그대로 사용하지 않는다.

## 토큰

| 역할 | 값 | 사용 |
|---|---|---|
| 바탕 | `#0D141C` | 본문 배경 |
| 내비게이션 | `#091119` | 사이드바 |
| 표면 | `#15232E` | 카드·차트·입력 |
| 떠 있는 표면 | `#1B2B38` | 선택·호버·헤더 |
| 경계 | `#2B4050` | 카드·표 구분 |
| 본문 | `#ECF5F8` | 제목·중요 수치 |
| 보조 | `#A5BAC6` | 설명·시간·출처 |
| 포인트 | `#24C4E5` | 버튼·선택·핵심 시계열 |
| 매수/상승 | `#42D3A4` | 양수 값과 막대 |
| 매도/하락 | `#FF7885` | 음수 값과 막대 |

- 글꼴: macOS 기본 글꼴과 한국어 시스템 글꼴을 우선 사용한다. 외부 폰트 다운로드는 요구하지 않는다.
- 크기: 본문 14~15px, 보조 12~13px, 화면 제목 28~32px, 수치 22~26px.
- 간격: 8px 단위를 기본으로 카드 안쪽 16~20px, 화면 구역 사이는 24~32px.
- 모서리: 카드 12px, 버튼·입력 8px. 과한 그림자 대신 명확한 경계를 사용한다.

## 화면 구성

1. 사이드바: `대시보드` 단일 명칭, 다섯 화면 내비게이션, 공급자 상태. 로고와 부제는 만들지 않는다.
2. 화면 머리말: 한 줄 제목, 짧은 설명, 생성 버튼 또는 상태를 오른쪽에 배치한다.
3. 데이터 요약: 가격·기사 수·수급은 작은 카드나 메트릭으로 표시하고 출처·기준 시각을 가까이 둔다.
4. 분석 영역: 차트 우선, 원자료 목록 다음. 기사 목록은 처음 8개 이슈만 보이고 나머지는 펼치기로 열람한다.
5. 표·차트: 좌우 정렬과 단위를 통일한다. 양수·음수는 색 외에 부호와 텍스트로도 구분한다.

## 상태와 접근성

- 0건, 인증 누락, 일부 실패, 장 마감, 수신 대기를 명시한다. 빈 공간을 가상 데이터로 채우지 않는다.
- 인터랙티브 요소는 키보드로 조작 가능해야 한다.
- 보조 텍스트도 어두운 배경에서 읽을 수 있도록 충분한 대비를 유지한다.
- 긴 기사 제목은 잘리지 않고 줄바꿈하며, 펼친 목록에서도 원문 링크를 유지한다.
- 좁은 화면에서는 여러 카드보다 읽기 순서를 우선한다.

## 검증

- 아침·저녁·실시간·기록·설정 화면에서 동일한 색·글꼴·간격을 확인한다.
- 0건과 많은 기사, 데이터 오류 상태에서 차트·목록·버튼이 겹치지 않는다.
- 화면에 `YS` 표식이 남지 않고 이름은 `대시보드`로 보인다.
- 기존 Streamlit AppTest와 단위 테스트가 통과한다.
